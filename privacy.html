StudyFlow プライバシーポリシー

制定日：2026年11月23日

StudyFlow（以下「本アプリ」）における利用者の情報の取り扱いについて説明します。

1. 取得する情報

  • アカウント情報：メールアドレス、パスワード（ハッシュ化した形でサーバーに保存し、元のパスワードは保存しません）
  • Googleログイン利用時：Googleアカウントのメールアドレス等の基本情報
  • 学習データ：勉強時間、教科、メモ、単語、目標などの記録（ログイン時のみサーバーに保存されます。ログインしない場合、データは端末内だけに保存されます）

2. 利用目的

  • アカウントの登録確認メールの送信、ログイン認証のため
  • 学習データの保存・同期のため
  • アプリの改善、不具合対応のため

3. Google API の利用について

本アプリは次の目的で Google のサービスを利用します。

  • Gmail API：登録確認メールを送信するためだけに使います。利用者のメールを読むことはありません。
  • Google Drive：ログインした利用者本人の Google Drive に、学習データのバックアップを保存するために使います。他人のファイルにアクセスすることはありません。
  • Googleログイン：本人確認のために使います。

Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含みます）に従います。取得した情報を広告目的で使うこと、第三者に販売することはありません。

4. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。

5. データの削除

アカウントと学習データの削除を希望する場合は、下記のお問い合わせ先までご連絡ください。確認のうえ削除します。Google Drive に保存されたバックアップは、利用者自身の Google Drive から削除できます。

6. 安全管理

通信は HTTPS で暗号化し、サーバーへのアクセスは制限しています。パスワードはハッシュ化して保存します。

7. ポリシーの変更

本ポリシーを変更する場合は、このページでお知らせします。
