StudyFlow プライバシーポリシー

制定日：2026年11月23日／最終改定日：2026年11月24日

このプライバシーポリシーは、Androidアプリ「StudyFlow」（以下「本アプリ」）における利用者の情報の取得、利用、保存、共有について説明するものです。本アプリの運営者（以下「運営者」）は、本ポリシーに従って利用者の情報を取り扱います。

1. 運営者・お問い合わせ先

運営者：StudyFlow 運営者
お問い合わせ：nserver.admin@gmail.com

2. 取得する情報

本アプリが取得する情報は次のとおりです。

  • アカウント情報：アカウント登録時に、メールアドレスとパスワードを取得します。パスワードはハッシュ化した形でのみサーバーに保存し、元のパスワードを保存することはありません。
  • Googleログイン利用時の情報：Googleログインを選んだ場合、本人確認のために Google アカウントのメールアドレスと表示名を取得します。それ以外の Google アカウントの情報（メールの中身、連絡先など）を取得することはありません。
  • 学習データ：利用者が本アプリに記録した内容です。具体的には、勉強セッション（教科、開始・終了時刻、勉強時間）、教科の一覧、タスク、単語帳の単語と意味、学習ノート、1日の目標、アプリの設定が含まれます。学習データは、ログインしている場合にサーバーへ保存され、端末とサーバーの間で同期されます。ログインしていない場合、学習データは利用者の端末内だけに保存され、サーバーへ送信されることはありません。
  • サーバーのアクセスログ：サーバーの安全管理と不正アクセス防止のため、アクセス日時や IP アドレスなどがサーバーのログに記録される場合があります。

本アプリは、広告のための情報収集や、利用者の行動を追跡する解析ツールを使用していません。また、位置情報、端末の連絡先、写真などの情報を取得することもありません。

3. 利用目的

  • アカウント情報は、アカウント登録の確認メールの送信、ログイン時の本人認証、アカウントの管理のために利用します。
  • 学習データは、利用者本人の記録の保存・表示・同期（端末を変えた場合の引き継ぎを含む）のためだけに利用します。
  • アクセスログは、サーバーの安全管理、不正アクセスや不具合の調査のために利用します。

取得した情報を、上記の目的以外に利用することはありません。取得した情報を、広告目的で利用すること、第三者に販売することはありません。

4. Google API の利用について

本アプリは、次の目的で Google API を利用します。

  • Google ログイン（openid / email / profile）：利用者の本人確認のために利用します。取得するのはメールアドレスと表示名などの基本情報だけです。
  • Google Drive API：ログインした利用者本人の Google Drive に、その利用者自身の学習データのバックアップを保存・復元するために利用します。本アプリがアクセスするのは、本アプリ自身が作成したバックアップファイルだけです（drive.file の範囲）。利用者の他のファイルを開いたり、変更したりすることはありません。
  • Gmail API：アカウント登録時の確認メールを、運営者のメールアドレスから送信するためだけに利用します。利用者の Gmail の内容を読むことはありませんし、利用者のメールボックスにアクセスすることもありません。

本アプリによる Google API から取得した情報の利用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。具体的には、Google API で取得した情報を広告に使うこと、販売すること、目的外の第三者へ渡すことはありません。また、運営者がその内容を人の目で読むことは、本人の同意がある場合、セキュリティ上の調査に必要な場合、または法令に従う場合に限ります。

本アプリが Google API を、AI によって生成された私的な状況のシナリオ・画像・動画（当人の合意なく作成されたもの、いわゆる AI NCII）を作成するために使用することはありません。本アプリには画像や動画を生成する機能自体がありません。

5. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。学習データの保存・同期のために運営者の管理するサーバーを利用しますが、それ以外の外部サービスへ学習データを送信することはありません（Google Drive へのバックアップは、利用者本人の Google Drive に対して行うもので、第三者への提供にはあたりません）。

6. 保存期間とデータの削除

アカウント情報とサーバー上の学習データは、アカウントが有効な間保存します。アカウントと学習データの削除を希望する場合は、上記のお問い合わせ先までご連絡ください。本人確認のうえ、サーバー上のアカウント情報と学習データを削除します。Google Drive に保存されたバックアップは、利用者自身の Google Drive からいつでも削除できます。端末内のデータは、アプリをアンインストールするか、アプリのログアウト操作により削除できます。

7. 安全管理

アプリとサーバーの間の通信は HTTPS で暗号化します。パスワードはハッシュ化して保存し、サーバーへの管理アクセスは制限しています。

8. ポリシーの変更

本ポリシーを変更する場合は、このページでお知らせし、改定日を更新します。重要な変更がある場合は、アプリ内でもお知らせします。

お問い合わせ

本ポリシーに関するお問い合わせは、nserver.admin@gmail.com までご連絡ください。
