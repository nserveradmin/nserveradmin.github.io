StudyFlow

勉強時間を記録して、目標づくりを助ける学習管理アプリ

このページは、Androidアプリ「StudyFlow」の公式情報ページです。ログインしなくても、どなたでもアプリの内容をご覧いただけます。

StudyFlow の目的

StudyFlow は、学生をはじめとする学習者が、自分の勉強時間と学習内容を記録し、日々の目標と進み具合を見える形にすることで、無理なく勉強を続けられるよう支援することを目的としたアプリです。勉強した時間を教科ごとに記録でき、集中を妨げるアプリの使用を抑えるフォーカスモードや、記録の統計表示も備えています。

主な機能

⏱️ タイマー記録：教科を選んで勉強時間を計測・保存
🎯 1日の目標：目標時間の設定と進捗表示、リマインダー通知
🚫 フォーカスモード：勉強中に指定アプリを開くと「勉強中」画面を表示
📊 記録タブ：連続記録日数、日・週・月・年ごとの合計、教科別の内訳とグラフ
☁️ ログインと同期：アカウントを作ると、学習データをサーバーと Google Drive に保存して引き継げます（ログインなしでも端末内だけで使えます）

Google サービスの利用について

StudyFlow は、Google ログインによる本人確認、アカウント登録時の確認メールの送信、および利用者本人の Google Drive への学習データのバックアップ保存のために、Google API を利用します。利用の詳しい内容はプライバシーポリシーに記載しています。

StudyFlow が Google API を、AI によって生成された私的な状況のシナリオ・画像・動画（当人の合意なく作成されたもの、いわゆる AI NCII）を作成するために使用することはありません。本アプリには、画像や動画を生成する機能自体がありません。
